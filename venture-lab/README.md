# Cross-Border Venture Lab

纯静态投资展示页，包含两个早期项目：

1. Bambu Lab 3D打印设备与本地服务（新西兰 / 巴基斯坦）
2. 藏医文化健康内容与体验（中国 / 新西兰）

## 文件

- `index.html`：页面结构与文案
- `styles.css`：响应式视觉样式
- `script.js`：预算切换、移动导航、滚动动效与复制按钮

## 本地预览

直接打开 `index.html`，或运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/venture-lab/`。

## GitHub Pages

本目录位于 `kndhjk/portfolio` 的 `master` 分支。如果该仓库已从根目录发布 GitHub Pages，页面地址通常为：

`https://kndhjk.github.io/portfolio/venture-lab/`

## 修改联系信息

当前合作按钮跳转到 GitHub 主页。可在 `index.html` 搜索 `contact-actions`，替换成邮箱、微信二维码或预约链接。

## 说明

- 项目为市场验证展示，不构成医疗建议或收益承诺。
- Bambu Lab代理范围、进口和保修安排应以品牌方及当地法规的书面确认文件为准。
